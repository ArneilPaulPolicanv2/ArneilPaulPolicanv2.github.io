# Arneil Paul Polican

Personal portfolio site for [arneilpaulpolicanv2.github.io](https://arneilpaulpolicanv2.github.io).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Pushes to `main` deploy via GitHub Actions (Pages). You can also publish manually:

```bash
npm run deploy
```

After the first Actions run, set the repo Pages source to **GitHub Actions** in
Settings → Pages.
